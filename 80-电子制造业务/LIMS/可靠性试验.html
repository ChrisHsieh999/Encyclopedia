可靠性试验

AI 生成 · 待核对制造业务LIMS可靠性试验更新于 2026-10-21

⚠ 待核对：各项可靠性试验的具体条件（温度、湿度、时间、循环数、判定限值）我只核实了部分标准的名称与编号（IPC-TM-650 2.6.7 的标题、JESD22-A101/A104/A110 的名称、IEC 60068-2-11 的版本、IPC-9701 的名称及新版情况），数值条件来自通行做法和记忆，没有拿到付费标准正文核对，表中凡标"示例"的数字一律以客户规范、公司标准、标准正文为准。IPC-9701 目前资料显示 A 版（2006）已被 B 版（2022）取代，但不同网站状态不一致，请到 IPC 官网确认。IPC-TM-650 的 2.6.25、2.6.3.7、2.6.27 的编号与标题请再核对。你们实验室的试验排期、箱体管理和 LIMS 实现方式未知，请对照你们的系统核实。SQL 与 Python 均已在本机实际运行。

本篇是 LIMS 系列第 8 篇。读完你应该能：说清 PCB/PCBA 常见的可靠性试验各考验什么；会写出一份"试验计划—样品—周期—检测点—结果"的表结构；用 SQL 做到期检测点提醒和试验箱排期冲突检测；理解 Weibull 分布在失效数据分析中的用处。

一句话定义 ​

可靠性试验是把产品放进比日常使用更严酷（更热、更潮、更抖、更反复）的环境里，在较短时间内暴露它未来可能出现的失效，用来评估"产品能用多久、哪里先坏"。

先修知识 ​

  • PCB制造流程、SMT与电子组装流程：知道 PCB（印制电路板）和 PCBA（装配好元件的板）、焊点、回流焊。
  • LIMS：样品、检测任务、结果的基本模型。
  • 检测任务与结果录入、仪器管理与校准：试验箱也是一种要校准、要管理的"仪器"。
  • 会读简单 SQL。

它解决什么问题 ​

出厂检验（AOI、ICT、FCT）只能告诉你"现在能不能工作"，回答不了"用三年会不会坏"。现场故事：一批车载板出厂全部测试通过，装车半年后在南方雨季陆续出现间歇性故障。事后分析：板子在高湿环境下，相邻线路之间长出了导电的金属丝（离子迁移，Ionic Migration；板子内部沿玻纤出现的叫 CAF，Conductive Anodic Filament，导电阳极丝），造成漏电。如果当初做过温湿度偏压试验，这个批次的设计缺陷（线距太小 + 助焊剂残留）早就在实验室里暴露了。

可靠性试验解决：

  1. 设计验证：新产品、新材料、新工艺上线前验证；
  2. 批次监控：量产中定期抽样，确认工艺没有漂移；
  3. 客户要求：汽车、医疗、工业客户会指定试验项目与条件；
  4. 失效分析：出问题后复现。

LIMS 在其中的作用：把长周期、多阶段、占设备的试验管起来。一次试验少则几十小时，多则 1000 小时（约 42 天）以上，要保证每个检测点按时做、箱子不被排冲突、结果能追溯到哪块板、哪个周期。

核心概念 ​

常见试验类型 ​

下表条件仅为示例（行业常见值，非标准原文），真正执行以客户规范和标准为准。

试验考验什么一句话做法常见条件（示例）参考标准（名称已核/待核）
高低温循环（Temperature Cycling，TC）不同材料热胀冷缩不一致导致的焊点疲劳开裂样品在高温与低温之间反复循环，通电监测电阻如 -40 ℃ 到 +125 ℃，每循环约 1 小时，500～1000 次JESD22-A104 Temperature Cycling（已核名称）；IPC-9701（焊点性能试验，待核数值）
热冲击（Thermal Shock）更快的温度突变，考验通孔、镀层、界面高温箱与低温箱之间快速转移样品（数秒到数十秒）如 -55 ℃ 到 +125 ℃，转移 < 10 sIPC-TM-650 2.6.7 Thermal Shock & Continuity, Printed Board（标题已核）；JESD22-A106（待核）
温湿度偏压（THB）潮湿 + 电压导致的漏电、离子迁移、腐蚀恒温恒湿箱里给样品加偏压放置常见 85 ℃ / 85 %RH，约 1000 小时JESD22-A101 Temperature and Humidity Bias Test（名称已核）
高加速温湿度应力（HAST）同 THB 但用更高温度和压力把时间缩短加压的高温高湿箱常见 130 ℃ / 85 %RH，约 96 小时JESD22-A110 Highly-Accelerated Temperature and Humidity Stress Test（名称已核）
离子迁移 / CAF内层或表面线路间长出导电丝在高温高湿下加偏压，持续监测绝缘电阻随板材与客户而定IPC-TM-650 2.6.25 CAF 类方法（待核）；2.6.3.7 表面绝缘电阻 SIR（待核）
盐雾（Salt Spray / Salt Mist）沿海、车载环境的腐蚀喷盐水雾如 5 % NaCl，35 ℃，24～96 小时IEC 60068-2-11 Test Ka（2021 版已核存在）；ASTM B117（待核）
振动（Vibration）运输、运行中的机械疲劳、连接器松动、焊点裂振动台按谱扫频或随机振动按产品使用场景定义IEC 60068-2-6（正弦）、IEC 60068-2-64（随机）（待核）
跌落（Drop）冲击对焊点、元件的损伤规定高度、规定面自由落体如 1 m，多个面各一次IEC 60068-2-31 / JESD22-B111（待核）
老化（Burn-in）早期失效（"婴儿期"）通电、一般在偏高温度下运行一段时间，剔除早夭的如 48～168 小时JESD22-A108 等（待核）
可焊性（Solderability）引脚、焊盘能否被焊料良好润湿浸锡或润湿平衡法，看润湿面积依标准与镀层而定J-STD-002（元件）、J-STD-003（PCB）（待核）
回流次数（Multiple Reflow）板子能否承受多次回流焊（双面、返修）而不起泡分层按回流曲线过炉 N 次后检查如 3～6 次（无铅）IPC-TM-650 2.6.27 类（待核）

一个重要的视角：失效的"浴盆曲线" ​

产品故障率随时间的典型形状像一只浴盆：

  • 早期失效期：刚上线，缺陷样品先坏，故障率高并下降 —— burn-in 就是为了把它们在出厂前筛掉；
  • 偶然失效期：故障率低且平稳，使用寿命的主体；
  • 耗损期：材料老化，故障率重新上升 —— TC、THB 等寿命试验主要评估这段。

加速试验与加速因子 ​

做 1000 小时试验不等于只考验 1000 小时的寿命。提高温度、湿度、应力可以让失效机理更快发生，加速因子（Acceleration Factor，AF）说明试验 1 小时相当于使用多少小时。温度加速最常用 Arrhenius 模型：

AF = exp( Ea/k × (1/T_use − 1/T_stress) )

Ea 是失效机理的激活能（eV），k 是玻尔兹曼常数 8.617×10⁻⁵ eV/K，温度用开尔文。例如 Ea = 0.7 eV，使用温度 55 ℃，试验 125 ℃：AF 约 77.7（实验里算出来的），1000 小时约等效 8.9 年。注意 Ea 取多少取决于失效机理，必须有依据；不同机理（腐蚀、迁移、焊点疲劳）用不同模型（如 THB 常用 Peck 模型，TC 用 Coffin-Manson 模型），这里只演示 Arrhenius 的计算，不代表这个数字可以直接用。

试验计划—样品—周期—中间检测点—结果 ​

一次试验的信息结构：

试验计划(Plan) ──< 样品(Unit)      每块板在计划里有编号
       │
       ├──< 检测点(Checkpoint)    0 h, 168 h, 336 h, 500 h, 1000 h ... 每个点要做什么检查
       │
       └── 试验箱(Chamber)         在哪个箱子，哪段时间
  • 计划：谁发起、什么试验、什么条件、起止时间、用哪个箱子。
  • 样品：哪些样品（引用共享表 Sample），计划内给每块编号 1..n。
  • 周期/检测点：到第几小时（或第几次循环）要取出来测一次，比如电阻、外观、绝缘电阻、切片。到点没测就是漏检。
  • 结果：每个检测点每个样品的结果；失效时记录失效时间/循环数（这是 Weibull 分析的输入）。判定标准通常是"电阻变化超过初始值的某个百分比算失效"，具体由标准或客户规定。

试验排期与在箱管理 ​

试验箱数量有限，每个试验要占几百到上千小时，所以：

  1. 排期：新试验要选一个在这段时间空闲的箱子，两个计划的时间区间不能在同一个箱子重叠；
  2. 在箱管理：实时知道哪个箱子里放着哪个计划、预计什么时候出箱、下一个检测点是什么时候；
  3. 异常处理：停电、箱体故障、温度超限时，要记录中断时间并评估试验是否有效。有的标准规定中断后要补时间或重做；
  4. 箱体校准：试验箱的温湿度要校准，到期不能用（同 仪器管理与校准）。

业务视角 ​

角色做什么
研发 / 质量工程师提出试验需求，指定标准、条件、样品数
可靠性工程师制定试验计划，判定与出报告
试验员样品入箱、取出、做检测点测试、记录
客户提出要求，接收报告

流程：收到需求 → 评审（条件、样品数、周期、费用）→ 排期（确认箱子可用）→ 样品接收与标识 → 初始测试（0 h）→ 入箱 → 按检测点出箱测试 → 完成 → 终测 → 失效分析 → 出报告（见 报告与签发）。

KPI：试验按期完成率；检测点按时率；试验箱利用率；一次通过率；失效分析闭环率。

技术视角 ​

表设计 ​

在共享表 Sample（见 样品管理）之外新增：

表关键列说明
ChamberChamberNo, ChamberType, Status试验箱，也可以当作 Instrument 的一种
RelPlanPlanNo, TestType, Condition, ChamberId, StartAt, TotalHours, EndAt(计算列), Status试验计划
RelUnitPlanId, SampleId, UnitNo, FailAtCycle计划内的样品，失效循环数（NULL=未失效）
RelCheckpointPlanId, AtHours, DoneAt, Result检测点，到期时间 = 开始时间 + AtHours

设计要点：

  • EndAt 做成计算列（DATEADD(HOUR, TotalHours, StartAt)），避免和 StartAt 不一致；
  • 检测点到期时间也用 StartAt + AtHours 算，不单独存，如果试验延后开始，所有检测点自动顺延；
  • 检测点 UNIQUE (PlanId, AtHours)，防止重复建点；
  • 结果的细节（每块板的电阻值）可以复用 检测任务与结果录入 的 TestTask / TestResult，一个检测点生成一批检测任务。

到期提醒与冲突检测的核心 SQL ​

  • 提醒：WHERE DoneAt IS NULL AND 到期时间 < 现在 + 24 小时，逾期的和即将到期的一起查；
  • 冲突：两个时间区间 [S1, E1) 与 [S2, E2) 重叠的充要条件是 S1 < E2 AND E1 > S2。这个写法比"分情况讨论"安全，一次覆盖所有重叠形态。

逐步例子 ​

场景：2026-10-21 08:00，实验室有两个在跑的试验。

  • REL-0001：THB，85 ℃/85 %RH 偏压，1000 小时，2026-10-01 08:00 入 CH-01。检测点 0、168、336、500、1000 小时。0、168 已完成。
  • REL-0002：温度循环，-40～125 ℃，每循环 1 小时，1000 小时，2026-10-10 08:00 入 CH-02。检测点 0、250、500、750、1000。0 已完成。

手算：

  • REL-0001 的 336 h 点 = 10-01 08:00 + 14 天 = 10-15 08:00，已过 6 天 = 144 小时 → 逾期 144 小时；
  • 500 h 点 = 10-01 08:00 + 20 天 20 小时 = 10-22 04:00，距离现在 20 小时 → 即将到期；
  • REL-0002 的 250 h 点 = 10-10 08:00 + 10 天 10 小时 = 10-20 18:00 → 已逾期 14 小时。
  • REL-0001 结束 = 10-01 08:00 + 1000 小时 = 11-12 00:00。

现在要新增一个试验想在 10-20 08:00 起占用 CH-01：与 REL-0001（到 11-12 00:00）重叠 → 冲突，最早可以 11-12 00:00 开始。

03_rel_demo.sql：

sql
USE Lab_lims2;
SET NOCOUNT ON;
DECLARE @Now DATETIME2 = '2026-10-21 08:00';       -- 实验里固定“现在”，真实系统用 SYSDATETIME()
-- 1) 到期/逾期提醒：未完成、且 24 小时内到期或已过期
SELECT p.PlanNo, c.AtHours, CONVERT(VARCHAR(16), DATEADD(HOUR, c.AtHours, p.StartAt), 120) AS DueAt,
       CASE WHEN DATEADD(HOUR, c.AtHours, p.StartAt) < @Now THEN N'逾期' ELSE N'即将到期' END AS Flag,
       DATEDIFF(HOUR, @Now, DATEADD(HOUR, c.AtHours, p.StartAt)) AS HoursLeft
FROM RelCheckpoint c JOIN RelPlan p ON p.Id = c.PlanId
WHERE c.DoneAt IS NULL AND p.Status = N'Running'
  AND DATEADD(HOUR, c.AtHours, p.StartAt) < DATEADD(HOUR, 24, @Now)
ORDER BY DueAt;
-- 2) 在箱管理：每个箱子现在的占用情况和最早可用时间
SELECT ch.ChamberNo, ch.ChamberType, ISNULL(p.PlanNo, N'-') AS PlanNo,
       ISNULL(CONVERT(VARCHAR(16), p.EndAt, 120), N'空闲') AS FreeAfter
FROM Chamber ch LEFT JOIN RelPlan p ON p.ChamberId = ch.Id AND p.Status = N'Running'
ORDER BY ch.ChamberNo;
-- 3) 排期冲突检测：新计划想占 CH-01，2026-10-20 08:00 起 1000h
DECLARE @NewStart DATETIME2 = '2026-10-20 08:00', @NewEnd DATETIME2 = DATEADD(HOUR, 1000, '2026-10-20 08:00');
SELECT N'冲突' AS Chk, p.PlanNo, CONVERT(VARCHAR(16), p.StartAt, 120) AS S, CONVERT(VARCHAR(16), p.EndAt, 120) AS E
FROM RelPlan p WHERE p.ChamberId = 1 AND p.Status IN (N'Planned', N'Running')
  AND p.StartAt < @NewEnd AND p.EndAt > @NewStart;      -- 两段区间重叠的标准写法
-- 4) 换到不冲突的时间：CH-01 现有计划结束后才能开始
SELECT CONVERT(VARCHAR(16), MAX(EndAt), 120) AS EarliestStartOnCH01 FROM RelPlan WHERE ChamberId = 1 AND Status IN (N'Planned', N'Running');
-- 5) 计划总览：样品数、检测点完成进度
SELECT p.PlanNo, p.TestType, (SELECT COUNT(*) FROM RelUnit u WHERE u.PlanId = p.Id) AS Units,
       CONCAT(SUM(CASE WHEN c.DoneAt IS NOT NULL THEN 1 ELSE 0 END), '/', COUNT(*)) AS CheckpointsDone
FROM RelPlan p JOIN RelCheckpoint c ON c.PlanId = p.Id GROUP BY p.Id, p.PlanNo, p.TestType ORDER BY p.PlanNo;

实验二：Weibull 与加速因子（Python） ​

Weibull 分布是可靠性里最常用的寿命分布。两个参数：

  • 形状参数 β：β < 1 早期失效；β ≈ 1 随机失效；β > 1 耗损失效（焊点疲劳通常 β 明显大于 1）；
  • 特征寿命 η：63.2 % 的样品失效时的寿命。

累计失效率 F(t) = 1 − exp(−(t/η)^β)。把它取两次对数就变成直线：ln(−ln(1−F)) = β·ln t − β·ln η，所以可以用中位秩回归：把失效时间从小到大排，第 i 个的 F ≈ (i − 0.3)/(n + 0.4)（Bernard 近似），对 ln t 做线性回归，斜率就是 β。

下面用 8 块板热循环到失效的数据演示（完全数据：全部失效；如果试验结束时还有没坏的，需要用带删失的方法，本脚本不处理）。

weibull.py，只用标准库：

python
"""Weibull 中位秩回归（完全数据，无删失）。只用标准库。"""
import math, statistics

# 8 块 PCBA 做温度循环到焊点开裂失效，记录失效时的循环数（升序）
fails = [420, 610, 750, 870, 960, 1100, 1280, 1500]
n = len(fails)

# Bernard 近似中位秩：F_i = (i - 0.3) / (n + 0.4)
F = [(i - 0.3) / (n + 0.4) for i in range(1, n + 1)]
x = [math.log(t) for t in fails]                       # ln t
y = [math.log(-math.log(1 - f)) for f in F]            # ln(-ln(1-F))
fit = statistics.linear_regression(x, y)               # y = beta*x + b
beta = fit.slope
eta = math.exp(-fit.intercept / beta)                  # 特征寿命：63.2% 失效时的循环数
r = statistics.correlation(x, y)

print(f"n = {n}, 形状参数 beta = {beta:.2f}, 特征寿命 eta = {eta:.0f} 次循环, R^2 = {r*r:.3f}")
B10 = eta * (-math.log(0.9)) ** (1 / beta)              # 10% 失效时的寿命
print(f"B10（10% 失效）= {B10:.0f} 次循环")
t = 500
F_t = 1 - math.exp(-((t / eta) ** beta))
print(f"{t} 次循环时累计失效率 F = {F_t*100:.1f}%，可靠度 R = {(1-F_t)*100:.1f}%")

# 复核：手工用最小二乘公式再算一遍 beta，必须与库函数一致
mx, my = sum(x) / n, sum(y) / n
beta2 = sum((a - mx) * (b - my) for a, b in zip(x, y)) / sum((a - mx) ** 2 for a in x)
assert abs(beta - beta2) < 1e-9

# 加速试验：Arrhenius 加速因子 AF = exp(Ea/k * (1/T_use - 1/T_stress))，温度用开尔文
Ea, k_B = 0.7, 8.617e-5                          # Ea 取 0.7 eV 仅作演示，真实值要按失效机理查
T_use, T_stress = 55 + 273.15, 125 + 273.15
AF = math.exp(Ea / k_B * (1 / T_use - 1 / T_stress))
print(f"Arrhenius 加速因子（55C -> 125C, Ea=0.7eV）= {AF:.1f}，试验 1000 h 约等效 {1000*AF/8760:.1f} 年")

运行：

预期输出：

n = 8, 形状参数 beta = 2.65, 特征寿命 eta = 1061 次循环, R^2 = 0.999
B10（10% 失效）= 454 次循环
500 次循环时累计失效率 F = 12.7%，可靠度 R = 87.3%
Arrhenius 加速因子（55C -> 125C, Ea=0.7eV）= 77.7，试验 1000 h 约等效 8.9 年

解读：β = 2.65 说明是耗损型失效（越用越容易坏）；η = 1061 次循环；B10 寿命（10 % 失效）= 454 次循环；500 次循环时累计失效率约 12.7 %。如果客户要求"500 次循环失效率不超过 10 %"，这批就不满足。脚本里用手工最小二乘公式复核了 β，两种算法一致。样本只有 8 个，估计的不确定度很大，真实评估要看置信区间。

常见坑与排查 ​

现象原因办法
检测点漏做靠人记到期提醒 + 逾期升级（通知主管）
试验结果不可比初始状态没测必须有 0 h 初测，后面都和它比
样品混了没有逐块标识每块板独立编号（板码），计划内再编号
箱体温湿度不准没校准、探头漂移箱体纳入仪器管理，试验中用独立探头监测
中途停电无记录记录中断；评估是否补时间
把加速因子当寿命忽略失效机理Ea 要有依据，结果只作相对评价
时间用本地时间算夏令时、跨班次统一时区；用 UTC 存、显示时转本地
样品数太少统计无意义按标准或客户规定样品数；Weibull 至少要有足够的失效点

练习题与答案 ​

1. 为什么温度循环会让焊点开裂？ 答：元件（陶瓷）、焊料、PCB（玻纤环氧）的热膨胀系数不同，温度变化时伸缩量不同，焊点被反复拉扯，产生疲劳裂纹。

2. REL-0001 的 500 h 检测点什么时候到？ 答：10-01 08:00 + 500 h = 10-01 + 20 天又 20 小时 = 10-22 04:00。

3. 新试验想占用箱子 [10-20 08:00, 11-30 08:00)，已有计划 [10-01 08:00, 11-12 00:00)，冲突吗？ 答：冲突。10-01 < 11-30 且 11-12 > 10-20 同时成立。

4. 为什么不直接把检测点的到期时间存成一列？ 答：存了就有两处真相：计划推迟开始时忘了改检测点时间就出现不一致；用 StartAt + AtHours 计算就不会不一致。

5. β = 0.7 的样品组说明什么？ 答：β < 1 说明故障率随时间下降，偏向早期失效（工艺缺陷或装配问题），应考虑增加 burn-in 或查工艺，而不是改设计寿命。

6. 动手：把实验里的 @Now 改成 '2026-10-22 08:00'，预期哪些检测点会变成"逾期"？ 答：500 h 点（10-22 04:00）从"即将到期"变成逾期；REL-0002 的 500 h 点（10-30 20:00）距离超过 24 小时不出现。

小结 ​

  • 可靠性试验用严酷环境暴露潜在失效：TC/热冲击考验热疲劳，THB/HAST/CAF/盐雾考验潮湿腐蚀迁移，振动/跌落考验机械，burn-in 筛选早期失效，可焊性与回流次数考验工艺窗口。
  • 试验数据结构：计划—样品—检测点—结果，加上试验箱的排期与在箱管理。
  • 检测点的到期时间用 StartAt + AtHours 计算；排期冲突用区间重叠公式 S1 < E2 AND E1 > S2。
  • Weibull 的 β 与 η 帮助判断失效类型和寿命；加速因子只能在有依据的失效机理下使用。
