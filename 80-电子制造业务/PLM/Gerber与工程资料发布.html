Gerber与工程资料发布

AI 生成 · 待核对制造业务PLMPCB更新于 2026-10-21

⚠ 待核对：Gerber 的命令（%FS、%MO、%ADD、D01/D02/D03、M02）和 FileFunction 属性取值已对照 Ucamco 的 Gerber 规范（2024.05 版）核实；Excellon 命令对照维基百科；IPC-2581 的来源和联盟信息来自 ipc2581.com 与行业报道，其最新修订号、各 EDA 软件的支持程度没有逐项核实；ODB++ 的出处（由 Valor 提出，现属哪家公司）来自通用知识，未联网核实。板厂能做的最小线宽、孔径等数值各厂不同，以你们合作板厂的工艺能力文件为准；你们自己的制造包发布清单请对照公司实际流程核实。本篇的解析器与校验器已在本机运行，样例是手写的最小文件，不是真实产品。

本篇是 PLM 系列第 5 篇。读完你应该能：说出一套 Gerber 文件包含哪些层、各是什么作用；看懂 Gerber 和钻孔文件里最基本的几条命令；知道钢网文件、贴片坐标文件（CPL）、BOM 文件在制造包里的位置；理解 CAM 工程审核（DFM）在做什么；用清单化的方式发布工程资料；并写出能解析最小 Gerber、校验 CPL 与 BOM 是否对得上的 Python 程序。

一句话定义 ​

Gerber 是把 PCB 的每一层图形（铜、阻焊、丝印、板框等）描述成一系列"画线"和"盖章"命令的文本文件格式，是设计软件向板厂交付设计数据的事实标准；工程资料发布则是把这些文件连同钻孔文件、钢网文件、贴片坐标、BOM 一起，作为一个受控的"制造包"交给下游，并在发出前逐项检查。

先修知识 ​

  • PCB制造流程：知道一块多层板要做内层、层压、钻孔、外层、阻焊、字符，每一步的"底片"来自哪一层 Gerber。
  • SMT与电子组装流程：知道钢网印锡膏、贴片机按坐标贴装，才明白钢网文件和坐标文件是给谁的。
  • 产品数据与文件管理：制造包里每个文件都要有编号、Rev、状态。
  • BOM在PLM与ERP间的流转：BOM 文件从哪来。

它解决什么问题 ​

现场故事：硬件工程师导出了 Gerber，板厂 CAM 工程师打开发现：

  • 少了阻焊层的文件，板厂只好打电话问；
  • 钻孔文件的孔位和铜层上的焊盘差了一个 0.5 mm 的偏移，因为导出时坐标原点选错了；
  • 板框文件没封闭，缺一条边，没法铣外形。

好在这些都在板厂的 CAM 审核（DFM，Design for Manufacturability，可制造性设计检查）阶段被发现，来回沟通耽误了 3 天。更糟的情况是没发现：板子做出来了，孔位偏了，整批报废。

所以发布制造包之前，要有一份逐项检查的清单，最好还有自动化检查：层齐全吗？孔和焊盘对得上吗？坐标文件和 BOM 的位号一致吗？这就是本篇要做的事。

核心概念 ​

一块板由哪些 Gerber 层组成 ​

层作用对应的制造工序FileFunction 例子（规范中的写法）
铜层（Copper）每一层的线路和焊盘内层图形、外层图形，见 PCB制造流程Copper,L1,Top、Copper,L2,Inr、Copper,L4,Bot
阻焊（Solder mask）阻焊油墨要开窗的位置（焊盘处露铜）阻焊Soldermask,Top
丝印（Legend）位号、标识、logo字符Legend,Top
钢网/锡膏层（Paste）需要刷锡膏的位置给钢网厂开口，见 治具与钢网管理Paste,Top
板框（Profile）外形轮廓成型（铣切）Profile,NP
钻孔（Drill）孔位和孔径钻孔Plated,1,2,PTH（镀铜孔）、NonPlated,1,2,NPTH

说明：Profile,NP 中 NP 表示非镀铜（Non-Plated），P 表示镀铜；钻孔里的 1,2 表示这个钻孔文件从第 1 层钻到第 2 层；PTH 是 Plated Through Hole（镀通孔）。这些取值我对照 Ucamco 规范原文核对过。

Gerber 文件长什么样 ​

Gerber 是纯文本（7 位 ASCII），人能直接读。据维基百科，当前的"扩展 Gerber"（RS-274X）在 1998 年发布；2014 年的 X2 版本增加了属性（metadata，元数据），比如这个文件是哪一层、哪个焊盘是 SMD 焊盘；旧的标准 Gerber（RS-274-D）已在 2014 年废止，它需要另外一个"光圈表"文件。

最基本的命令（本篇解析器只实现这些）：

命令含义
%FSLAX26Y26*%坐标格式：整数 2 位、小数 6 位。X5000000 就是 5.000000
%MOMM*%单位毫米（%MOIN*% 是英寸）
%TF.FileFunction,Copper,L1,Top*%文件属性：这是第 1 层顶层铜
%ADD10C,0.200000*%定义 10 号光圈（aperture）：圆形，直径 0.2 mm；R,1.0X0.6 是矩形
D10*选用 10 号光圈
X5000000Y5000000D02*D02 = 移动到这个坐标，不画
X20000000Y5000000D01*D01 = 用当前光圈画线到这个坐标
X5000000Y5000000D03*D03 = 在这个坐标闪一下（盖章），常用来画焊盘
X10000000D03*坐标省略 Y = 沿用上一个 Y
M02*文件结束

比喻：光圈像不同形状的印章或笔头；D02 抬笔移动，D01 落笔画线，D03 盖一个章。Gerber 里还有区域填充（G36/G37 之间的轮廓）、正负极性（%LPD*% 亮/暗）等，本篇不展开。

数值的单位陷阱：X5000000 在"2.6 格式"下是 5 mm，在"2.4 格式"下就是 500 mm。所以解析时必须先读 %FS 才能换算，这也是板厂 CAM 审核第一步就要对的东西。

Excellon 钻孔文件 ​

钻孔数据常用 Excellon 格式（以 Excellon Automation 公司的钻孔机命名）。据维基百科，这个格式原本是专有的、规格有歧义，尤其是坐标和单位。常见内容：

M48            头部开始
METRIC         单位毫米
T1C0.3         定义 1 号刀，直径 0.3 mm
%              头部结束
G05            钻孔模式
T1             选 1 号刀
X20.0Y15.0     在 (20, 15) 钻一个孔
M30            文件结束

本篇的样例用了带小数点的坐标，不用处理"省零"（零压缩）的歧义；真实钻孔文件也可能是不带小数点的整数坐标，需要按头部声明的格式换算。

IPC-2581 与 ODB++：把多个文件合成一个 ​

Gerber 的短板：一层一个文件，加上钻孔、BOM、坐标等一堆文件，文件之间靠人对应，缺一个、版本错一个都不容易发现。于是有了"智能"格式：

  • IPC-2581（也称 IPC-DPMX）：IPC 在 2004 年发布，用一个文件（XML 格式）承载整板的制造描述数据，据 ipc2581.com，它是开放、双向的标准，由 IPC-2581 联盟（2011 年由 Cadence 牵头成立）维护推广。行业报道称其设计时借鉴了 Valor 捐出的 ODB++ 的公开版本。
  • ODB++：由 Valor 公司提出的另一种单目录格式，板厂和设计软件的支持很广。

一句话：Gerber 是"一堆图"，IPC-2581 和 ODB++ 是"带说明书的一个包"。但现实是 Gerber 加钻孔文件加 BOM 的组合仍然是最普遍的交付方式，所以本篇实验以它为主。IPC-2581 的最新修订号、各家软件的支持度请到 ipc2581.com 核对。

制造包里还有什么 ​

文件给谁作用
Gerber 各层 + 钻孔板厂做裸板
钢网文件（锡膏层 Gerber，加厚度和开口要求）钢网厂开钢网，见 治具与钢网管理
贴片坐标文件 CPL（Pick & Place，也叫 Centroid）SMT 编程每个元件的位号、中心坐标、旋转角、贴装面
BOM 文件SMT、采购、仓库每个位号用什么料
装配图、组装说明SMT/插件/组装方向、极性、特殊工艺
测试规范测试工站ICT/FCT 的测试项
制造说明（Fab notes）板厂层叠、板厚、铜厚、表面处理、阻抗、颜色等

CPL 的典型列：Designator（位号）、Footprint（封装）、Mid X、Mid Y（元件中心坐标，毫米）、Rotation（旋转角度）、Layer（Top/Bottom）。不同 EDA 软件导出的列名和旋转角定义各不相同，导入贴片机程序前要核对。

CAM 工程审核（DFM） ​

板厂收到资料后，CAM 工程师会做一轮审核（常称 CAM 审核或 DFM 检查）：

  • 层与板框：层数、叠层是否符合，板框是否封闭；
  • 线宽线距：最小线宽、间距是否在板厂工艺能力内；
  • 孔：最小孔径、孔到孔和孔到线的距离、环宽（annular ring，孔周围留的铜环）是否够；
  • 阻焊：开窗大小、阻焊桥（相邻焊盘之间的阻焊条）是否太窄；
  • 丝印：丝印是否压在焊盘上；
  • 孔与焊盘对准：钻孔文件和铜层是否同一坐标系。

发现问题时，板厂提出 EQ（Engineering Question，工程问题），由设计方确认或修改后重发。越早发现问题成本越低，所以设计方发布前自己也应当做一遍同类检查（这就是下面实验在做的事的一小部分）。具体数值标准以板厂工艺能力文件为准。

业务视角 ​

谁做什么：

  • 硬件/Layout 工程师：导出 Gerber、钻孔、CPL、BOM；
  • 工艺工程师：核对制造说明，准备钢网和 SMT 程序；
  • 文控：把制造包作为一个受控版本发布，记录发给了哪家板厂；
  • 板厂 CAM：审核、回复 EQ；
  • 采购：与板厂对接，下单。

技术视角 ​

  • 制造包作为一个受控对象：用 ReleasePackage(PkgId, ProductCode, Rev, Status, ReleasedBy, ReleasedAt) 表示，ReleasePackageItem(PkgId, FileName, FileFunction, Sha256) 表示其中每个文件。发布时对每个文件算 SHA-256，之后板厂或产线拿到的文件可以核对哈希，确认和发布时一致。包的状态流转和"同一产品同一时间只有一个已发布包"用 产品数据与文件管理 中同样的状态机和筛选唯一索引实现。上面的表只是设计草图，本篇没有单独运行。
  • 自动检查接在发布流程里：提交审核前自动跑检查，有 error 就不让提交。
  • 文件功能靠属性，不靠文件名：X2 的 TF.FileFunction 属性比文件扩展名可靠。文件名里写 .GTL、.GBL 之类的习惯很常见，但维基百科指出用扩展名表示层的做法不被推荐；本篇的检查器读属性。
  • 单位和格式先读后用：先读 %FS 和 %MO，再换算坐标，不要假定。
  • 浮点比较：判断"孔位和焊盘是否重合"时，坐标要先四舍五入到固定小数位再比较，不能直接比较浮点数是否相等。

逐步例子：手算一份最小 Gerber ​

样例是 A100 的一小块（40 mm × 25 mm）的简化设计，所有文件手写。顶层铜 A100-F_Cu.gbr 里有：

  • 走线：从 (5, 5) 画到 (20, 5)，再画到 (20, 15)。长度：水平 20 − 5 = 15 mm，垂直 15 − 5 = 10 mm，合计 25 mm；
  • 4 个矩形贴片焊盘（D11）：(5,5)、(10,5)、(30,10)、(30,20)；
  • 2 个过孔焊盘（D12，直径 0.8）：(20,15)、(35,15)；
  • 2 个插件焊盘（D13，直径 1.8）：(10,20)、(12.54,20)（间距 2.54 mm，即 0.1 英寸，插针常见间距）；
  • 所以闪烁（D03）共 4 + 2 + 2 = 8 次，画线（D01）2 段。

板框 A100-Edge.gbr：矩形 40 × 25，周长 2 × (40 + 25) = 130 mm，4 段。

钻孔 A100-PTH.drl：2 个 0.3 mm 过孔（对应 D12），2 个 1.0 mm 插件孔（对应 D13），共 4 孔，位置与顶层的 D12、D13 焊盘完全重合。

第 2 步：新建 pkg_check.py（解析器、制造包检查、CPL 校验器）：

python
"""最小 Gerber(RS-274X) / Excellon 解析器 + 制造包检查 + 贴片坐标(CPL)校验器。
用法：python pkg_check.py <目录>      目录里放 .gbr / .drl / bom.csv / cpl_*.csv
"""
import csv
import math
import re
import sys
from collections import Counter
from pathlib import Path

# ---------- Gerber ----------
def parse_gerber(path):
    info = dict(function=None, unit=None, dec=None, apertures={}, flashes=Counter(),
                draws=Counter(), length=0.0, bbox=None, errors=[], ended=False)
    cur, x, y, pts = None, 0.0, 0.0, []
    info["flashpts"] = []
    for raw in Path(path).read_text(encoding="utf-8").splitlines():
        line = raw.strip()
        if not line:
            continue
        if line.startswith("%"):                                  # 扩展命令 %...*%
            body = line.strip("%").rstrip("*")
            if body.startswith("FSLA"):
                m = re.fullmatch(r"FSLAX(\d)(\d)Y(\d)(\d)", body)
                info["dec"] = int(m[2])                           # 小数位数
            elif body in ("MOMM", "MOIN"):
                info["unit"] = body[2:].lower()
            elif body.startswith("TF.FileFunction,"):
                info["function"] = body.split(",", 1)[1]
            elif body.startswith("ADD"):
                m = re.fullmatch(r"ADD(\d+)([A-Z]),(.+)", body)
                info["apertures"][int(m[1])] = (m[2], m[3])       # 形状, 参数
            continue
        cmd = line.rstrip("*")
        if cmd == "M02":
            info["ended"] = True
        elif cmd in ("G01", "G02", "G03"):
            continue
        elif re.fullmatch(r"D(\d+)", cmd) and int(cmd[1:]) >= 10:   # 选光圈
            cur = int(cmd[1:])
            if cur not in info["apertures"]:
                info["errors"].append(f"选了没定义的光圈 D{cur}")
        else:
            m = re.fullmatch(r"(?:X(-?\d+))?(?:Y(-?\d+))?D0([123])", cmd)
            if not m:
                info["errors"].append(f"看不懂的行：{cmd}")
                continue
            scale = 10 ** info["dec"]
            nx = int(m[1]) / scale if m[1] else x                 # 坐标省略 = 沿用上一个值
            ny = int(m[2]) / scale if m[2] else y
            op = m[3]
            if op == "1":                                         # D01 画线
                info["draws"][cur] += 1
                info["length"] += math.hypot(nx - x, ny - y)
            elif op == "3":                                       # D03 闪一下（焊盘）
                info["flashes"][cur] += 1
                info["flashpts"].append((nx, ny))
            x, y = nx, ny
            pts.append((x, y))
    if pts:
        xs, ys = [p[0] for p in pts], [p[1] for p in pts]
        info["bbox"] = (min(xs), min(ys), max(xs), max(ys))
    info["points"] = pts
    return info

# ---------- Excellon（只支持小数点坐标的简单写法）----------
def parse_drill(path):
    info = dict(function=None, tools={}, holes={}, errors=[])
    tool = None
    for line in Path(path).read_text(encoding="utf-8").splitlines():
        line = line.strip()
        m = re.match(r";\s*#@!\s*TF\.FileFunction,(.+)", line)
        if m:
            info["function"] = m[1]
        m = re.fullmatch(r"T(\d+)C([\d.]+)", line)
        if m:
            info["tools"][int(m[1])] = float(m[2]); info["holes"][int(m[1])] = []
        elif re.fullmatch(r"T\d+", line):
            tool = int(line[1:])
            if tool not in info["tools"]:
                info["errors"].append(f"用了没定义的刀 T{tool}")
        else:
            m = re.fullmatch(r"X(-?[\d.]+)Y(-?[\d.]+)", line)
            if m and tool in info["holes"]:
                info["holes"][tool].append((float(m[1]), float(m[2])))
    return info

REQUIRED = ["Copper,L1,Top", "Copper,L2,Bot", "Soldermask,Top", "Legend,Top", "Profile,NP", "Plated,1,2,PTH"]

def check_package(d):
    d = Path(d)
    errs, found, outline = [], {}, None
    for f in sorted(d.glob("*.gbr")):
        g = parse_gerber(f)
        found[g["function"]] = f.name
        errs += [f"{f.name}: {e}" for e in g["errors"]]
        if not g["ended"]:
            errs.append(f"{f.name}: 没有以 M02 结束（文件可能被截断）")
        print(f"{f.name:16} {str(g['function']):18} {g['unit']} 小数{g['dec']}位 光圈{len(g['apertures'])}个 "
              f"焊盘闪烁{sum(g['flashes'].values()):2d} 画线{sum(g['draws'].values()):2d}段 线长{g['length']:6.2f}mm")
        if g["function"] == "Profile,NP":
            outline = g["bbox"]
        if g["function"] == "Copper,L1,Top":
            top = g
    dr = None
    for f in sorted(d.glob("*.drl")):
        dr = parse_drill(f)
        found[dr["function"]] = f.name
        errs += [f"{f.name}: {e}" for e in dr["errors"]]
        print(f"{f.name:16} {str(dr['function']):18} " + "，".join(f"T{t} 孔径{dr['tools'][t]}mm x{len(h)}" for t, h in dr["holes"].items())
              + f"  共 {sum(len(h) for h in dr['holes'].values())} 孔")
    for need in REQUIRED:
        if need not in found:
            errs.append(f"缺少必需的层：{need}")
    if outline:
        print(f"板框：{outline[2]-outline[0]:g} x {outline[3]-outline[1]:g} mm")
    # 每个钻孔位置，顶层铜上都应该有一个焊盘（D03 闪烁）
    if dr and "Copper,L1,Top" in found:
        pads = {(round(x, 3), round(y, 3)) for x, y in top["flashpts"]}
        for t, holes in dr["holes"].items():
            for h in holes:
                if (round(h[0], 3), round(h[1], 3)) not in pads:
                    errs.append(f"孔 T{t} 在 {h} 处，顶层铜没有对应焊盘")
    return errs, outline

# ---------- 贴片坐标校验 ----------
def check_cpl(cpl_path, bom_path, outline):
    bom = {}
    for row in csv.DictReader(open(bom_path, encoding="utf-8")):
        if row["Mount"] != "SMD":
            continue                                              # 插件不进贴片坐标
        for ref in row["Designator"].split(","):
            bom[ref.strip()] = row["Footprint"]
    errs, seen = [], set()
    for n, row in enumerate(csv.DictReader(open(cpl_path, encoding="utf-8")), start=2):   # 第 1 行是表头
        ref = row["Designator"]
        where = f"第{n}行 {ref}"
        if ref in seen:
            errs.append(f"{where}: 位号重复")
        seen.add(ref)
        if ref not in bom:
            errs.append(f"{where}: BOM 里没有这个贴片位号")
        elif bom[ref] != row["Footprint"]:
            errs.append(f"{where}: 封装 {row['Footprint']} 与 BOM 的 {bom[ref]} 不一致")
        if row["Layer"] not in ("Top", "Bottom"):
            errs.append(f"{where}: Layer 只能是 Top 或 Bottom，现在是 {row['Layer']}")
        if not 0 <= float(row["Rotation"]) < 360:
            errs.append(f"{where}: 旋转角 {row['Rotation']} 不在 [0,360)")
        x, y = float(row["Mid X"]), float(row["Mid Y"])
        if outline and not (outline[0] <= x <= outline[2] and outline[1] <= y <= outline[3]):
            errs.append(f"{where}: 坐标 ({x:g},{y:g}) 在板框之外")
    for ref in sorted(set(bom) - seen):
        errs.append(f"BOM 的 {ref} 在贴片坐标里找不到")
    return errs

if __name__ == "__main__":
    pkg = sys.argv[1]
    print("== 制造包检查 ==")
    errs, outline = check_package(pkg)
    print("制造包问题：", errs or "无")
    for cpl in sorted(Path(pkg).glob("cpl_*.csv")):
        e = check_cpl(cpl, Path(pkg) / "bom.csv", outline)
        print(f"== {cpl.name} ==")
        for line in e:
            print("  ", line)
        print(f"   共 {len(e)} 个问题" if e else "   通过")

常见坑与排查 ​

坑说明与办法
单位/小数位不一致不同层用不同的 %FS、%MO，叠起来对不上。每个文件先读头部，检查器要核对一致
钻孔文件省零格式不带小数点的 Excellon 要按 LZ/TZ 和格式换算，导出时尽量选带小数点的格式
坐标原点不一致铜层和钻孔用了不同原点，孔位整体偏移。检查孔与焊盘的重合
板框不封闭铣外形无法执行。检查首尾坐标重合，并检查文件完整
文件被截断邮件或传输中断。检查 M02 和文件哈希
把 Gerber 层当成最终层阻焊层 Gerber 描述的是"开窗"，不是"油墨"。极性理解错会整个反过来
CPL 旋转角约定不同不同 EDA 软件的 0 度、正方向定义不同，贴片机导入后要首件核对
CPL 里底面元件镜像底面元件坐标是否镜像，各软件不同，需要核对
位号对不上 BOM自动对比，别靠眼睛
制造包版本与 BOM 版本不一致发布时检查并记录，两者同属一次变更
重要文件只靠文件名表达层用 X2 属性；没有属性时再看文件名

练习题与答案 ​

  1. %FSLAX26Y26*% 下，坐标 X12540000 是多少毫米（单位为毫米）？ 答：整数 2 位、小数 6 位，12540000 即 12.540000 mm。
  2. D01、D02、D03 分别是什么？ 答：D01 用当前光圈画线到该点；D02 移动到该点不画；D03 在该点闪一下（盖章，常画焊盘）。
  3. 一块板框矩形 60 × 40 mm，周长是多少？ 答：2 × (60 + 40) = 200 mm。
  4. 为什么要检查"每个孔在铜层上有焊盘"？ 答：孔和焊盘不重合，说明坐标系或数据错误，做出来会钻偏、孔环不足或断路，整批报废的风险大。
  5. 为什么 CPL 不包含插件元件（如 J1）？ 答：CPL 是给贴片机的，插件元件不是贴片机贴装，常由手工或波峰焊工序处理；所以 BOM 里用 Mount 区分，检查时只比较贴片元件。
  6. IPC-2581 比 Gerber 好在哪？ 答：一个文件包含整板的层、钻孔、BOM、位号等关联信息，不容易出现文件缺失或不匹配；Gerber 是一层一个文件，靠人工对应。但 Gerber 仍然最普及。
  7. 为什么坐标比较要先四舍五入再判断相等？ 答：浮点数的二进制误差会让本应相等的两个数略有差别；固定小数位后再比较更稳。

小结 ​

  • 一套 Gerber = 若干铜层 + 阻焊 + 丝印 + 板框 + 钻孔；钢网来自锡膏层；坐标 CPL 和 BOM 给贴片用。
  • Gerber 是命令文本：光圈定义、选光圈、D02 移动、D01 画线、D03 盖章、M02 结束；坐标要按 %FS 和 %MO 换算。
  • 发布前用清单加自动检查：层齐全、格式一致、孔对焊盘、CPL 对 BOM。
  • 制造包要作为一个受控版本发布，文件带哈希，保留"发给谁、哪一版"的记录。
