自动化仓储

AI 生成 · 待核对制造业务WMS自动化SMT更新于 2026-10-21

⚠ 待核对：本篇以概念为主。设备类型和分层架构来自维基百科；智能料塔的容量、功能、接口来自厂商网页的宣传介绍（cts、Hawker Richardson、FutureATT），厂商之间说法不一，我没有独立验证。真实的立体库、AGV/AMR、料塔设备我无法在本机运行验证；实验里只是用 SQL 模拟"WCS 回报任务状态"的软件逻辑，不涉及任何真实设备。WCS 在 ISA-95 层级中的位置没有统一说法，是我的归纳，请对照你们厂的架构。实验的 SQL 和输出是我在本机 SQL Server LocalDB 上实际运行得到的。

本篇是 WMS 系列的一篇。读完你应该能：说出立体库（AS/RS）、智能料塔、AGV/AMR 各是什么、适合什么场景；画出 WMS → WCS → 设备控制器 的分层；知道 WMS 与自动化设备之间交互什么、哪里最容易出问题；理解"任务状态机 + 幂等回报"为什么是自动化仓储接口的核心。

一句话定义 ​

自动化仓储是用机器代替人去完成存取和搬运：设备（立体库堆垛机、料塔机械手、AGV/AMR 小车）负责"把东西送到、取出来"，软件分层负责"取什么、什么时候取、取完记账"。WMS 管业务和库存，WCS 管设备调度，设备自己的控制器（PLC）管具体动作。

先修知识 ​

  • WMS：知道仓库管理系统管什么。
  • ISA-95：知道企业系统分层（ERP 在上，MES/WMS 在中，设备控制在下）。
  • WMS与MES交互：知道备料、发料、线边仓、上料这条物料流。
  • MSD湿敏元件管理：料塔常常要兼顾湿敏元件的存放。
  • 对 PLC 有基本概念会更好（设备控制器通常是 PLC）。

它解决什么问题 ​

现场故事：

  • 一家做 SMT 的工厂，料号有四五千种，小料盘（Reel）放在货架上，找一盘要看标签、走过去、翻货架，平均几分钟。每次换线要备几十盘料，备料占了换线时间的大头。
  • 找错料：型号相近的两种电容（同封装不同容值），拿错一盘上线，要到 AOI 或功能测试才发现，已经做了一批不良板。
  • 先进先出靠人记，没有强制：新来的在外面，老的埋在后面，越来越老，最后过期、呆滞（见 退料与呆滞料）。
  • 仓库面积不够，货架往上叠高，人工够不着。

自动化仓储试图解决：更快（机器存取）、更准（系统指令，不靠人脑）、更省地（向高处发展）、更可控（每次存取都有记录，能强制先进先出，能管环境）。

代价是：投资大，改造难，系统复杂，设备坏了会让整个仓库停摆。

核心概念 ​

常见设备 ​

设备是什么典型用途
AS/RS（Automated Storage and Retrieval System，自动存取系统）由计算机控制的设备，把货物放进指定库位、再取出来高密度、大批量、对准确性要求高的仓库
智能料塔（SMT Reel Tower / Smart Rack）专为 SMT 料盘设计的竖直存取柜，内部有机械手电子厂存放几百到几千盘卷料
AGV（Automated Guided Vehicle，自动导引车）沿预设路径（磁条、反光板、二维码等）行驶的搬运车在固定路线上搬运料箱、料车
AMR（Autonomous Mobile Robot，自主移动机器人）自己用传感器建图、规划路径的移动机器人布局会变、路径要灵活的场景
输送线/分拣机传送带、滑道、分拣装置料箱、周转箱的连续输送

AS/RS 的类型（据维基百科）：

  • 单元负载式（Unit-load）：搬运整托盘，窄巷道、很高的货架，用堆垛机；
  • 小型负载式（Mini-load）：搬运料箱、托盘、纸箱，适合品种多的场合；
  • 穿梭车式（Shuttle）：每层货架上有独立的穿梭车水平移动，由升降机负责垂直移动；
  • 垂直升降式/旋转式（Vertical Lift Module、Carousel）：货架像"电梯"或"旋转木马"，把货送到操作员面前。

AS/RS 的好处按维基百科的说法：减少人工、库存更准、存储更密、减少体力劳动。它的取货逻辑是：操作员（或上层系统）指定物料类型和数量，软件找到库位、安排取货、指挥设备送到出口，库存记录随存取自动更新。

AGV 与 AMR：维基百科说，AGV 靠地上的线、磁条、无线电、摄像头、磁铁或激光来导航；AMR 一词有时用来强调"不需要额外的导引设施"。厂商资料普遍说法是：AMR 用 SLAM（同时定位与建图）自己建地图、遇障碍绕行，改布局只需重新建图；AGV 路线固定、遇阻会停下，适合稳定的大批量路线。两者的成本孰高孰低，各家说法不一，不要凭印象。多辆车时需要调度系统（车队管理）做交通控制、任务分配和充电管理。

智能料塔（SMT 常用） ​

电子厂的料盘小、品种多，料塔把几百到几千盘料放在一个封闭的塔里，机械手按指令取放。厂商资料里常见的特点（厂商宣传，未独立验证）：

  • 容量：例如 cts 称其 REEL Tower 支持 7 到 15 英寸料盘，塔高可达约 4 米，单个基本单元最多 1520 盘，组合后最大可达约 4176 盘（7 英寸、8 mm 料带）；
  • 控制：中央控制单元管理取放，每次机械手动作都有数字记录，实时识别和跟踪料盘；
  • 拣选引导：有的货架是灯光引导（Pick-to-Light），LED 指示要取的库位；有的支持"先取尾料"、先进先出规则；
  • 联动：与 MES/ERP 双向同步，取放确认回传；cts 通过自家的中间件 AXES 连接 MES 或 ERP；
  • 环境：可选配受控环境存放湿敏元件，帮助避免 MSD 存放超时；
  • 点料：有的方案配 X-Ray 点料机，取回的尾料入塔前自动点数，把数量回传系统。

料塔对 SMT 厂的最大价值通常是：按工单自动出库一整套料，由系统保证拿对、先进先出，并给 MSD 提供受控存放，再配合 SMT上料防错与站位表 做上料确认。

三层分层：WMS、WCS、设备控制器 ​

维基百科对仓储控制系统（WCS，Warehouse Control System）的描述是三层结构：

  1. WMS（上层）：处理业务，订单、库存分配、单据；非实时；
  2. WCS（中层）：把 WMS 的工作量翻译成实时任务，分配任务、决定每个决策点的路径、提供操作界面、收集绩效数据；它把 WMS 和底层实时控制隔开；
  3. 设备控制器（下层）：通常是 PLC 或专用实时 PC，读传感器、扫码枪、秤，驱动电机，让设备真正动起来。

对照 ISA-95：ERP 在第 4 层，WMS/MES 在第 3 层；WCS 和设备控制器靠近第 2 层及以下（实际产品里常把 WCS 和 WMS 的功能混在一起，也有的 WCS 由设备厂商提供）。关键是记住职责分离：

层关心不关心
WMS这个料哪批、多少、该给哪个工单机械手怎么走、传感器信号
WCS任务排队、设备忙闲、异常恢复工单、库存的业务含义
设备控制器电机、位置、安全业务

接口方式 ​

WMS ⇄ WCS（或料塔的控制软件）之间怎么通信，没有统一标准，常见的有：

方式说明取舍
HTTP/REST、Web Service请求/响应，简单易调试回报要轮询或回调；对断线要做重试
TCP Socket自定义报文，实时性好要自己处理粘包、心跳、重连
中间表双方读写同一数据库的表简单，但耦合紧，要防重复读取
消息队列（如 MQTT）异步、解耦要运维消息服务，见 MQTT
OPC UA 等设备协议设备层数据读取更多用于设备到 WCS 层，见 OPC-UA
厂商中间件如料塔厂商提供的集成中间件省事，但要关注接口文档和版本

不管哪种方式，下面这些要点必须有：

  1. 任务号：每个任务有唯一编号，两边用它对应；
  2. 状态机：任务的状态（已创建 → 已下发 → 执行中 → 完成/失败）有明确定义，只允许合法流转；
  3. 幂等：同一个任务的"完成"回报重复发送，只处理一次（网络重试一定会发生）；
  4. 只在完成时动库存：不要在下发时就扣库存，否则设备失败了账就错了；
  5. 异常有出口：失败、超时、设备断线、人工干预，都要有明确的处理和告警；
  6. 对账：设备侧如果也有库存记录（很多立体库自带），必须与 WMS 定期核对，防"双账"。见 库存账与账实一致。

业务视角 ​

SMT 料塔的一个典型流程 ​

  1. 入塔：来料收货、贴内部标签（见 物料标签与条码）后，扫码入塔，系统指定库位（或由塔自动分配），机械手存放；MSD 料入塔即视为"进入受控环境"，可以写 Cabinet 事件，暂停车间寿命；
  2. 工单备料：工单下发后，WMS 算出需要的料（齐套检查），生成出库任务；
  3. 出库：料塔按任务取出这套料（或灯光引导人取），MSD 料出塔时写 TakeOut 事件；
  4. 上线：配送（人工、AGV/AMR）到线边，上料员扫码上料；
  5. 尾料回塔：工单完工或换线，尾料扫码、点数，回塔，系统更新标签与库存。

谁受益、谁受影响 ​

角色变化
仓管员不再满货架找料，更多是处理异常和补料
计划员备料可预约，缩短换线备料时间
质量先进先出由系统强制，MSD 有受控存放和记录
IT多了一个要维护的接口，设备停机时要有应急方案

KPI ​

  • 拣选准确率；出库响应时间（任务下发到料到出口）；
  • 空间利用率（库位占用率）；
  • 设备可用率与故障时长；
  • 账实一致率（设备库存与 WMS 库存）；
  • 投资回报：节省的人工、缩短的换线时间、减少的错料损失，要和设备投资比较。

技术视角 ​

任务表与状态机 ​

最小的设计：

表字段说明
TaskTaskNo、LabelNo、FromLoc、ToLoc、Status、UpdatedAtWMS 下发给 WCS 的出库/入库任务
TaskTransitionFromStatus、ToStatus合法的状态流转，写成数据，不写死在代码里
InvTxn见共享核心表任务完成时才写库存流水

状态流转：

Created → Sent → Running → Done
             ↘       ↘
              Failed   Failed

把"当前状态必须是合法的上一个状态"写进 UPDATE ... WHERE，更新行数 0 就说明是重复回报或非法流转，忽略即可，和 工单管理 里防止重复下发是同一个技巧。

失败与超时 ​

  • 下发了没响应：超过 N 秒没回报"已接收"，重发（因为任务号唯一，对方应幂等处理）；
  • 执行中设备故障：WCS 回报 Failed，WMS 保持库存不动，通知人工处理；
  • WMS 以为失败，设备其实完成了（回报丢了）：靠定期对账发现（库位上料盘位置与账不符）；
  • WMS 宕机时设备回报：回报要能排队重发，或 WCS 本地缓存。

与 MES 的联动 ​

料塔、AGV/AMR 的任务通常由 WMS 发出，但 MES 的事件也会触发：工单下发 → 备料任务；换线计划 → 预约出库；上料确认 → 更新标签状态。这些事件怎么在 MES、WMS、WCS 之间流转，见 WMS与MES交互、MES与WMS衔接。

-- WCS 回报任务状态。只有"从合法的上一个状态"才能前进（条件写在 WHERE 里），Done 时才动库存并记流水
CREATE PROCEDURE dbo.usp_TaskReport @taskNo varchar(20), @to varchar(10), @now datetime2(0) AS
BEGIN
    SET XACT_ABORT ON;
    BEGIN TRAN;
    UPDATE t SET Status = @to, UpdatedAt = @now
      FROM dbo.ATask t JOIN dbo.ATransition x ON x.FromStatus = t.Status AND x.ToStatus = @to
     WHERE t.TaskNo = @taskNo;
    IF @@ROWCOUNT = 0 BEGIN ROLLBACK; SELECT N'忽略：任务不存在、已处理过，或状态流转不合法' AS Result; RETURN; END
    IF @to = 'Done'
    BEGIN
        INSERT dbo.ATxn (TaskNo, LabelNo, FromLoc, ToLoc)
        SELECT t.TaskNo, t.LabelNo, r.Loc, t.ToLoc FROM dbo.ATask t JOIN dbo.AReel r ON r.LabelNo = t.LabelNo WHERE t.TaskNo = @taskNo;
        UPDATE r SET Loc = t.ToLoc FROM dbo.AReel r JOIN dbo.ATask t ON t.LabelNo = r.LabelNo WHERE t.TaskNo = @taskNo;
    END
    COMMIT;
    SELECT N'已接受 -> ' + @to AS Result;
END
GO

常见坑与排查 ​

现象 / 坑原因与办法
WMS 和立体库各有一份库存，对不上双账。明确谁是主，定期对账；设备库存只作为位置参考
任务下发时就扣了库存设备失败后账错。只在完成回报时动库存
重复回报造成重复入账缺幂等。用任务号和状态流转条件挡住

料塔里的 MSD 状态没同步入塔、出塔要写 Cabinet/TakeOut 事件，见 MSD湿敏元件管理
接口文档和实际行为不一致联调时逐条验证状态、异常、超时；让厂商提供测试环境或模拟器
尾料回塔数量不准回塔前点数（人工或点料机），更新标签；见 物料标签与条码

练习题与答案 ​

  1. WMS、WCS、PLC 的分工各是什么？ 答：WMS 管业务与库存（取什么、给谁）；WCS 把任务变成实时的设备调度与路径；PLC 驱动具体的机械动作和传感器。
  2. 为什么"库存在任务完成时才动"，不在下发时动？ 答：任务可能失败或超时，下发时就扣库存会让账与实物不一致；完成回报才是物料真正移动的证据。
  3. WCS 重复回报"完成"，怎样避免重复入账？ 答：任务号唯一 + 合法流转检查：UPDATE ... WHERE Status = 合法上一个状态，行数为 0 就忽略；流水表上对任务号建唯一约束作为第二道保险。
  4. AGV 和 AMR 的主要区别是什么？ 答：AGV 依赖预设的导引设施（磁条、反光板等），路线固定；AMR 靠传感器和地图自主导航，遇障碍绕行，改布局更方便。厂商说法在成本上各不一致，要按具体项目评估。
  5. 料塔用于 MSD 料时，入塔、出塔应该写什么事件？ 答：入塔写 Cabinet（暂停车间寿命计时，前提是塔内环境满足干燥要求，以厂商和标准为准），出塔写 TakeOut（恢复计时）。
  6. 立体库自带库存记录，和 WMS 的库存冲突时以谁为准？ 答：应事先约定，通常以 WMS 为库存主，设备记录用于位置和对账。冲突要用盘点和流水排查，不能随意相互覆盖。

小结 ​

  • 自动化仓储用设备代替人存取和搬运：AS/RS、智能料塔、AGV/AMR、输送线。
  • 软件分三层：WMS（业务）、WCS（实时调度）、设备控制器（PLC），职责要分清。
  • SMT 料塔价值在于按工单自动出料、强制先进先出、受控存放 MSD，并与 MES/WMS 联动。
  • 接口核心：任务号、状态机、幂等、完成才动库存、异常有出口、与设备库存定期对账。
  • 投资大、依赖设备，设备停机要有应急方案；厂商资料是宣传，需要独立验证。
