NumPy与pandas

AI 生成 · 待核对AIPython数据分析更新于 2026-10-21

本篇是 AI 入门路径的第 5 篇，也是做所有数据分析和机器学习的"基本功"。读完你应该能：用 NumPy 做数组运算并理解广播；用 pandas 读 CSV、筛选、分组统计良率；知道常见的坑（缺失值、加权平均、视图与拷贝）。所有代码在 Python 3.12、NumPy 2.5.4、pandas 3.0.6 下实际运行，输出逐行贴出。

一句话定义 ​

NumPy 提供高效的多维数组（ndarray）和批量数学运算；pandas 在它之上提供带行名列名的表格（DataFrame），能像 Excel + SQL 一样读、筛、分组、汇总数据。

先修知识 ​

  • Python 基础：变量、列表、循环、函数。列表见 Python容器类型。
  • 读文件和异常处理：Python文件与异常。
  • 会写简单的 SQL SELECT … WHERE … GROUP BY 更好（见 SQL-Server），pandas 的很多操作可以一一对应。

它解决什么问题 ​

Python 自带的列表能存数据，但：

  1. 慢：要算 100 万个数，得写 for 循环，一个个乘；
  2. 啰嗦：想把每个数加 5，要写 [x + 5 for x in lst]；
  3. 没有表格概念：一张"批次 / 线别 / 日期 / 不良数"的表，用列表套列表很难做分组统计。

标准库里的 csv、statistics（见 Python标准库速览）可以读 CSV、算平均和标准差，数据小时够用。但数据一多、操作一复杂，用 NumPy 和 pandas 的代码量能缩到十分之一，速度也快得多（本机实测：对 100 万个数乘 2 再求和，NumPy 比纯 Python 循环快约 8–9 倍）。机器学习的库（scikit-learn实践）的输入输出也都是 NumPy 数组或 pandas 表格。

核心概念 ​

NumPy 的 ndarray ​

ndarray 是同类型元素组成的多维数组。属性：

  • shape：每个维度的长度，如 (2, 3) 表示 2 行 3 列；
  • dtype：元素类型，如 int64、float64；
  • axis：维度编号。axis=0 沿着行方向（对每列做运算），axis=1 沿着列方向（对每行做运算）。

向量化与广播 ​

向量化：对整个数组一次操作，不写循环。a + 5 就是每个元素加 5。

广播（broadcasting）：形状不同的数组也能运算，NumPy 自动把小的"拉伸"成大的。规则：从最后一个维度往前对齐，每个维度要么相等，要么其中一个是 1（或缺失）。例如 (2, 3) 的数组加一个 (3,) 的数组，后者会复制成两行；(3, 1) 加 (3,)，会变成 (3, 3)。不满足规则就报 ValueError。

pandas 的 Series 与 DataFrame ​

  • Series：一列数据，带索引（行标签）。
  • DataFrame：一张表，若干个 Series 按列拼成。每列可以是不同类型（文本、整数、小数、日期）。

常用操作对照 SQL：

例 1：NumPy 基础 ​

python
import numpy as np, pandas as pd
print("numpy", np.__version__, "pandas", pd.__version__)
a = np.array([230, 245, 250, 238])
print(a, a.dtype, a.shape)
print(a + 5, a * 2, a > 240)
print("mean", a.mean(), "std(总体)", round(a.std(), 3), "std(样本)", round(a.std(ddof=1), 3))
m = np.array([[1, 2, 3], [4, 5, 6]])
print(m.shape, m.T.shape, m.sum(axis=0), m.sum(axis=1))
print(np.arange(0, 10, 3), np.linspace(0, 1, 5), np.zeros((2, 2)))
# 广播
temps = np.array([[240.0, 245.0, 250.0],
                  [238.0, 244.0, 252.0]])      # 2 块板 x 3 个温区
offset = np.array([1.0, -2.0, 0.5])            # 每个温区一个校准偏移
print(temps + offset)
col = np.array([[10], [20]])
print((col + np.array([1, 2, 3])))
# 布尔筛选
print(a[a > 240], a[[0, 2]], a[1:3])

逐条解读：

  • a + 5：4 个温度各加 5，得 [235 250 255 243]；a > 240 得到布尔数组 [False True True False]。
  • 平均值：(230 + 245 + 250 + 238) / 4 = 963 / 4 = 240.75。
  • 标准差有两种：a.std() 默认除以 n（总体标准差）= 7.529；a.std(ddof=1) 除以 n−1（样本标准差）= 8.694。统计里分析抽样数据通常用样本标准差，而 NumPy 默认是总体的，这是一个常见的坑；pandas 的 .std() 默认 ddof=1。
  • m.sum(axis=0) 对每列求和：[1+4, 2+5, 3+6] = [5 7 9]；axis=1 对每行求和：[6, 15]。
  • 广播：temps 形状 (2, 3)，offset 形状 (3,)。offset 被"拉成"两行，和每块板的 3 个温区逐列相加：240+1 = 241，245−2 = 243，250+0.5 = 250.5，与输出一致。
  • col 形状 (2, 1)，加 (3,) 的 [1, 2, 3]，结果是 (2, 3)：第一行 10+[1,2,3] = [11, 12, 13]，第二行 20+[1,2,3] = [21, 22, 23]。
  • 布尔筛选 a[a > 240] 取出大于 240 的元素 [245, 250]；a[[0, 2]] 按位置取；a[1:3] 切片取第 1、2 个。

例 2：更多数组操作与两个典型的坑 ​

python
import numpy as np
a = np.arange(12).reshape(3, 4)
print(a)
print(a.mean(axis=0), a.mean(axis=1))
print(a - a.mean(axis=0))          # 每列减去列均值（中心化）
rng = np.random.default_rng(0)
print(rng.integers(0, 10, 5), rng.normal(0, 1, 3).round(3))
x = np.array([1, 2, 3]); y = np.array([[10], [20], [30]])
print((x + y).shape)
try:
    np.zeros((2, 3)) + np.zeros((2,))
except ValueError as e:
    print("ValueError:", e)
# 不良率矩阵：行=线别，列=班次
d = np.array([[6, 9, 4], [12, 5, 3]]); n = np.array([[200, 180, 220], [210, 190, 230]])
print((d / n * 100).round(2)); print(d.sum() / n.sum() * 100)
b = a[0:2, 1:3]; b[0, 0] = 99; print(a[0, 1])    # 切片是视图
c = a.copy()[0:2, 1:3]; c[0, 0] = -1; print(a[0, 1])
print(np.where(np.array([230, 245, 250, 238]) > 240, "OK", "LOW"))

要点：

  • np.arange(12).reshape(3, 4)：生成 0–11 并变成 3 行 4 列。
  • 中心化：a - a.mean(axis=0)，每列减去该列平均值，结果每列和为 0。机器学习预处理里经常这样做（见 线性回归 里的梯度下降）。
  • 随机数：用 default_rng(种子) 创建随机数发生器，固定种子可复现结果。
  • 广播失败：(2, 3) 和 (2,) 从最后一维对齐，3 对 2，既不相等又都不为 1，报错。要让它们能加，需要把 (2,) 变成 (2, 1)：np.zeros(2).reshape(2, 1)。
  • 不良率矩阵：d / n 逐元素相除，一次算出 6 个不良率（%）。总体不良率 = 39 / 1230 = 3.1707%——不是各格不良率的简单平均，要用总数相除（见下面 pandas 的"加权"）。
  • 切片是视图（view）：b = a[0:2, 1:3] 并没有复制数据，修改 b 会改到 a（a[0,1] 变成 99）。而 a.copy()[...] 是真正的拷贝，修改 c 不影响 a（a[0,1] 仍是 99，而不是 −1）。需要独立副本时请显式 .copy()。
  • np.where(条件, 值1, 值2)：条件成立取值 1，否则取值 2，类似 SQL 的 CASE WHEN。

例 3：用 pandas 读 CSV 并统计良率 ​

先写一份 CSV（8 个批次，第 7 批缺少不良数）。这是示意数据。

python
import pandas as pd
csv = """lot,line,date,panels,defects,peak_temp
L001,SMT1,2026-10-01,200,6,243.5
L002,SMT1,2026-10-01,180,9,238.0
L003,SMT2,2026-10-01,220,4,246.0
L004,SMT2,2026-10-02,210,12,236.5
L005,SMT1,2026-10-02,190,5,244.0
L006,SMT2,2026-10-02,230,3,247.5
L007,SMT1,2026-10-03,200,,242.0
L008,SMT2,2026-10-03,205,7,240.0
"""
open("lots.csv", "w", encoding="utf-8").write(csv)
df = pd.read_csv("lots.csv", parse_dates=["date"])
print(pd.__version__)
print(df.head(3)); print(df.dtypes); print(df.shape)
print(df.isna().sum())
print(df.describe().round(2))
df["defects"] = df["defects"].fillna(df["defects"].median())
df["yield_pct"] = ((df["panels"] - df["defects"]) / df["panels"] * 100).round(2)
print(df[["lot", "yield_pct"]])
print(df[df["yield_pct"] < 96])
print(df[(df.line == "SMT2") & (df.peak_temp > 240)][["lot", "peak_temp"]])
g = df.groupby("line").agg(lots=("lot", "count"), panels=("panels", "sum"), defects=("defects", "sum"))
g["yield_pct"] = ((g.panels - g.defects) / g.panels * 100).round(2)
print(g)
print("简单平均 vs 加权:", df.groupby("line")["yield_pct"].mean().round(2).to_dict())
print(df.groupby(["line", "date"])["defects"].sum())
print(df.sort_values("yield_pct").head(2)[["lot", "yield_pct"]])
other = pd.DataFrame({"line": ["SMT1", "SMT2"], "owner": ["张三", "李四"]})
print(df.merge(other, on="line")[["lot", "owner"]].head(3))
df.to_csv("out.csv", index=False, encoding="utf-8-sig")
print(open("out.csv", encoding="utf-8-sig").read().splitlines()[:2])

逐段解读：

  1. 读入：read_csv 自动推断类型。parse_dates=["date"] 把日期列解析成真正的日期类型，之后可按日期分组、排序。defects 因为有一个空值，变成了 float64（NaN 是浮点数），所以显示成 6.0。
  2. 类型显示：pandas 3.0 里文本列类型显示为 str；pandas 2.x 及以前显示 object，日期精度也可能是 datetime64[ns]。这是版本差异，不影响用法。
  3. 缺失值：isna().sum() 统计每列缺失个数，defects 有 1 个。describe() 里 defects 的 count 是 7 而不是 8，它自动跳过了缺失值。
  4. 填充：fillna(中位数) 用中位数 6 填补第 7 批（7 个已知值 3、4、5、6、7、9、12 的中位数是 6）。填充是一种假设，不是事实，在真实业务里要先弄清这条记录为什么缺（没录入？还是没有不良？）。
  5. 良率：(panels − defects) / panels × 100。第 1 批：(200 − 6) / 200 = 97%，与输出一致。
  6. 筛选：良率低于 96% 的是 L002 和 L004；"SMT2 且峰值温度高于 240"的是 L003、L006。多条件用 &（与）、|（或），每个条件必须加括号。
  7. 分组汇总：每条线先把 panels 和 defects 求和，再算良率。SMT1：(770 − 26) / 770 = 96.62%；SMT2：(865 − 26) / 865 = 96.99%。
  8. 简单平均 vs 加权：对每批的良率直接求平均，SMT1 得 96.59、SMT2 得 96.94，和加权算法（总数相除）不同。大批次和小批次权重应该不同，所以良率应当用总数算，而不是把百分比取平均。这是 MES 报表里最常见的口径错误之一。
  9. 多键分组：groupby(["line", "date"]) 得到每条线每天的不良数。
  10. 排序：sort_values("yield_pct") 升序，head(2) 取最差的两批。
  11. 连表：merge(other, on="line") 把负责人按线别合并进来，类似 SQL 的 INNER JOIN。
  12. 导出：to_csv(..., encoding="utf-8-sig") 带 BOM 的 UTF-8，用 Excel 打开中文不会乱码；index=False 不写出行号。

业务视角与技术视角 ​

业务视角：良率报表、不良 Pareto（按不良类型排序）、按线别 / 班次 / 料号的趋势对比，都是"分组汇总"。MES 里的报表系统能做固定报表，但临时想问"低温批次是不是良率更低"这类问题，用 pandas 几行代码就能回答。注意口径一致：良率是用总数算（直通率另有算法），时间窗、是否含返修，都要和现有看板对齐，否则数字对不上。参见 MES、SPC。

技术视角：数据通常在 SQL Server 里，pandas 可以直接把查询结果读进来（pd.read_sql，需要 SQLAlchemy 和 ODBC 驱动，本篇未在本机验证）。更稳妥的做法是：能在 SQL 里先 GROUP BY 聚合的，就在数据库里算，只把聚合后的小表交给 pandas 做分析；这也是你的 C# + SqlSugar 技术栈的优势——取数、清洗交给 SQL。pandas 擅长探索和建模，而不是替代数据库。

练习题与答案 ​

练习 1：a = np.array([3, 6, 9])，算 a * 2 + 1 和 a[a > 4]。

答案：a * 2 + 1 = [7, 13, 19]；a[a > 4] = [6, 9]。

练习 2：形状 (4, 1) 与形状 (3,) 的数组相加，结果形状是什么？形状 (4, 2) 与 (3,) 呢？

答案：(4, 1) + (3,) → (4, 3)（两边都被拉伸）。(4, 2) + (3,)：最后一维 2 与 3 既不相等又都不为 1，报 ValueError。

练习 3：用例 3 的数据，SMT1 在 10-01 的良率是多少？

答案：10-01 SMT1 有 L001（200 块，不良 6）和 L002（180 块，不良 9），合计 380 块，不良 15。良率 = (380 − 15) / 380 = 96.05%。代码：d = df[(df.line == "SMT1") & (df.date == "2026-10-01")]，再 (d.panels.sum() - d.defects.sum()) / d.panels.sum() * 100。

练习 4：为什么对每批良率直接取平均是错的？举例说明。

答案：批次大小不同，权重应不同。例：A 批 1000 块良率 99%，B 批 10 块良率 50%。简单平均 74.5%，加权为 (990 + 5) / 1010 = 98.51%，后者才反映真实情况。

练习 5（动手）：用 df.groupby("line")["peak_temp"].agg(["mean", "min", "max"]) 看每条线的温度范围，写出你观察到的现象。

答案：实测 SMT1 平均 241.875、最小 238.0、最大 244.0；SMT2 平均 242.5、最小 236.5、最大 247.5。SMT2 的温度波动范围（11 ℃）比 SMT1（6 ℃）更大。可对照 SMT1 的 4 个温度 243.5、238.0、244.0、242.0 手算验证。

小结 ​

  • NumPy 的 ndarray 做整批数学运算，不写循环；axis 决定沿哪个方向汇总；广播让形状不同的数组也能运算，规则从最后一维对齐。
  • pandas 的 DataFrame 是带列名的表：read_csv 读入，布尔条件筛选，groupby 分组汇总，merge 连表。
  • 良率要用总数相除，不要对百分比取平均；缺失值的填充是假设，要和业务确认。
  • 注意版本差异、编码问题、视图与拷贝、std 的 ddof。
  • 取数和聚合尽量交给数据库，pandas 专注分析和建模。
